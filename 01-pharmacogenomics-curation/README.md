# Pharmacogenomics & Drug–Gene Curation

## Project Overview

This portfolio project demonstrates my experience in pharmacogenomics (PGx) data curation and drug–gene annotation.

My professional experience includes working with genomic and pharmacogenomic information and organizing scientific data into structured formats for analysis and reporting.

This public project uses non-confidential example data to demonstrate my scientific curation and data-management skills.

## Curation Focus

The project covers:

- Pharmacogenomic data curation
- Variant and allele annotation
- Star allele information
- Drug–gene relationships
- Evidence and source assessment
- Structured biomedical data organization

## Example Data Fields
