# Variant Curation

## Project Overview

This portfolio project demonstrates my experience in genomic variant curation and scientific data interpretation.

My professional experience includes reviewing and curating disease-associated genetic variants using scientific literature and established genomic resources.

This public project uses non-confidential example data to demonstrate the general approach to variant curation.

## Curation Focus

The project covers:

- Disease-associated variant curation
- Variant identification and annotation
- Gene and variant information
- Scientific evidence review
- Literature-based interpretation
- Evidence assessment
- Structured genomic data organization

## Example Data Fields

The demonstration may include fields such as:

- Gene
- Variant
- Variant identifier
- Reference and alternate alleles
- Genomic position
- Variant consequence
- Disease/phenotype
- Evidence
- Source/reference

## Resources

The project demonstrates the use of publicly available genomic resources and scientific literature.
