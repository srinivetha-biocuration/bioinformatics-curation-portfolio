# NGS Quality Control & Microbiome Analysis

## Project Overview

This portfolio project demonstrates my experience working with an existing microbiome analysis pipeline and performing quality-control and downstream analysis steps on sequencing data.

My experience includes working with sequencing data through quality-control workflows using FastQC, fastp, and MultiQC, followed by downstream microbiome analysis and interpretation.

The project is presented using non-confidential examples to demonstrate my bioinformatics workflow knowledge and data-analysis skills.

## Workflow

The workflow includes:

- Sequencing data quality assessment
- FASTQ data processing
- Read quality control using FastQC
- Read preprocessing using fastp
- Quality-control report aggregation using MultiQC
- Downstream microbiome analysis
- Microbial profile interpretation
- Nutritional analysis based on microbiome results

## Quality-Control Tools

- FastQC
- fastp
- MultiQC
- Linux
- Existing/pre-built bioinformatics pipeline

## Downstream Analysis

Following sequencing quality control and preprocessing, the workflow supports:

- Microbiome data analysis
- Microbial profile assessment
- Interpretation of microbiome-related results
- Nutritional analysis
- Integration of microbiome findings with nutrition-related information
